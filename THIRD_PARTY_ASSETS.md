# Third-party visual assets

Only freely redistributable assets are pulled by `FreeAssetBootstrap`.
Downloaded files are intentionally ignored by Git and are fetched during Editor/Cloud preparation.

## Khronos glTF Sample Assets — CC0 car

- ToyCar — https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/ToyCar
- Direct GLB source used by Cloud Build:
  https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/ToyCar/glTF-Binary/ToyCar.glb
- License: Creative Commons Zero v1.0 Universal (CC0)
- Original car model: Guido Odendahl
- glTF extensions / scene composition: Eric Chadwick

This replaced the first AI-generated sports-car asset after the initial Windows build showed unacceptable visual quality.

## Policy

Do not add ripped models, branded game vehicles, copyrighted audio, or assets with unclear redistribution rights. New assets must have their source and license documented here before use.
